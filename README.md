# BDIX Server Tester

A modern, fast, and responsive web application built with Next.js (App Router), React, and Tailwind CSS to test and check the status of various BDIX (Bangladesh Internet Exchange) servers.

## Features

- **Concurrent Testing**: Tests multiple BDIX server addresses concurrently for faster results.
- **Status Categories**: Easily filter servers by their status (Open, Closed, Testing).
- **Search Functionality**: Quickly find specific servers by name.
- **Modern UI**: Clean and responsive user interface built with Tailwind CSS.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Deployment**: [Vercel](https://vercel.com/)
